# ADHD-RS 採点

ADHD-RS（18項目、各0–3点）の採点用Webアプリ。

- 奇数項目＝不注意、偶数項目＝多動・衝動性として、それぞれの小計と合計を算出
- 数字の連続入力（入力すると次の項目へ自動移動）と、ボタン選択の両方に対応
- 結果は「合計○○点(不注意○○ 多動○○)」の形式でコピー可能
- 入力内容は保存・送信されない（ブラウザ内でのみ計算）
- 項目文は著作権保護のため非掲載

## 使い方

公開ページ: https://mokobear-git.github.io/adhd-rs-calculator/

または `index.html` をダウンロードしてブラウザで開く（オフライン動作可）。
